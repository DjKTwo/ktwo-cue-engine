# KTWO Cue Engine

A free companion app for **djay Pro** on Windows and Mac. It suggests cue points, loops and a
mix order from djay's own track analysis and writes them into your djay library – always
keeping a backup first.

**Download, install steps, help and release notes: [djktwo.com/cueengine](https://djktwo.com/cueengine)**

## Download

| | |
|---|---|
| Windows 10/11 (djay Pro from the Microsoft Store) | [KTWO-Cue-Engine-Windows.zip](https://github.com/DjKTwo/ktwo-cue-engine/releases/latest/download/KTWO-Cue-Engine-Windows.zip) |
| Mac with Apple silicon (djay Pro from the Mac App Store) | [KTWO-Cue-Engine-Mac.zip](https://github.com/DjKTwo/ktwo-cue-engine/releases/latest/download/KTWO-Cue-Engine-Mac.zip) |

The beta is not code-signed yet: Windows may show "Windows protected your PC" (choose
**More info → Run anyway**), and macOS asks you to choose **Open Anyway** under
System Settings → Privacy & Security. On a Mac, also turn on KTWO Cue Engine under
**Full Disk Access** – djay keeps its analysis in a protected folder.
